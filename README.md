# Quafox-shopping-cart-Automation
# Selenium E-Commerce Automation Project

Automated end-to-end e-commerce workflow testing for the TutorialsNinja demo website using Selenium WebDriver and Python.

---

## Project Overview

This project automates a complete user shopping flow including:

- Navigating product categories
- Opening product pages
- Interacting with image carousel
- Updating product quantity
- Adding multiple products to cart
- Removing products from cart
- Validating success/error messages using assertions

---

## Tech Stack

- Python
- Selenium WebDriver
- ChromeDriver
- Page Object Model (POM)
